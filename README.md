# PRIMECHANGE 人材評価・育成システム

ホテル清掃スタッフの評価を、品質改善・人材育成・定着へつなげるための統合プロトタイプです。

## 成果物

- [人材評価・育成 統合戦略レポート](./PRIMECHANGE_タレントマネジメント統合レポート.html)
- [入力・自動集計対応の人材評価レポート](./人材評価レポート_PRIMECHANGE.html)

## 主な内容

- ホテル清掃に合わせた20項目・5領域の行動評価
- 重み付き100点集計とS〜Dランク
- 品質・安全が低い場合のランク上限制御
- AIによる評価根拠整理・育成Action Item生成仕様
- 人が最終判断するガバナンス
- 90日パイロット導入計画
- PRIMECHANGE公式ブランドカラー
- ブラウザ入力、印刷、PDF保存対応

## 使用方法

HTMLファイルをブラウザで開いて閲覧・入力します。正式運用前に、評価基準、個人情報の利用範囲、保存方法、評価者間の基準調整をパイロットで検証してください。

## 注意

本リポジトリは制度設計と画面のプロトタイプです。入力内容はブラウザを更新すると消えます。AI出力のみで採点、処遇、配置、契約に関する決定を行わないでください。
