# PRIMECHANGE 人材評価・タレントマネジメント（最強版）

ホテル清掃スタッフの評価を、品質改善・人材育成・定着へつなげるための統合プロトタイプです。
Claude Code と Codex が協働し、ダブル監査を経て統合した最強版を公開しています。

- **[人材評価・タレントマネジメント 最強版（index.html）](./index.html)**

- **[著名な人事評価理論 上位5選](./performance-appraisal-theories.html)**
  MBO、コンピテンシー、目標設定理論、BARS、360度評価の詳細ガイド

## 主な内容（全14セクション）

- システム全体構成図（インプット → AI集計 → 特徴抽出 → 助言生成 → 運用）
- 土台となる7つの人材育成理論 ＋ マズロー欲求段階
- ホテル清掃に合わせた20項目・5領域の行動評価（自動採点）
- 重み付き100点集計とS〜Dランク、品質・安全ゲート
- AIによる評価根拠整理・育成Action Item生成のプロンプト設計
- AIと人間の3層役割モデル／データ接続モデル（人物×現場×期間×評価項目）
- 公正性・個人情報・説明責任のガバナンス
- 30日／90日パイロット導入計画
- PRIMECHANGE公式ブランドカラー、ブラウザ入力・自動保存・印刷/PDF対応

## 使用方法

`index.html` をブラウザで開いて閲覧・入力します。入力は端末内（localStorage）に自動保存されます。
正式運用前に、評価基準・個人情報の利用範囲・保存方法・評価者間の基準調整をパイロットで検証してください。

## 注意

本リポジトリは制度設計と画面のプロトタイプです。個人の実データは含みません。
AI出力のみで採点・処遇・配置・契約に関する決定を行わないでください。最終判断は必ず人が行います。
